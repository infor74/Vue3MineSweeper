# MineSweeper

一个使用 Vue 3、TypeScript、Vite 和 Element Plus 实现的网页扫雷小游戏。

## 环境要求

- Node.js
- Yarn

## 运行

```bash
yarn install
yarn dev
```

开发服务器启动后，按终端显示的地址在浏览器中打开游戏。

## 难度

| 难度 | 棋盘大小 | 地雷数 |
| --- | ---: | ---: |
| Easy | 9 × 9 | 10 |
| Normal | 16 × 16 | 16 |
| Hard | 16 × 30 | 30 |

切换难度会生成该难度的新棋盘。计时器从首次有效左键点击并布雷后开始。

## 游戏操作

- **左键**：打开格子。首次有效左键点击的格子不会有地雷。
- **右键**：在未打开的格子上循环切换标记：无标记 → 旗子 → 问号 → 无标记。
- **重新开始**：重置当前难度的棋盘和计时器。

打开数字格可以看到其周围八格内的地雷数量。打开周围没有地雷的格子时，游戏会展开相邻的空白区域和边缘数字格；展开时会保留相邻格上的旗子和问号标记。直接左键点击问号格仍会打开它。

## 计时与胜负

踩到地雷会显示失败提示；确认提示后会重置当前游戏。所有真实地雷都被插上旗子时获胜，不要求打开所有安全格。错误位置上的旗子不会被当作正确标记，但会计入剩余地雷显示，因此计数可能低于零。

## 测试

```bash
yarn test
```

测试覆盖首击安全、首次布雷前插旗、空白展开时的标记行为、胜利判定和重置。
