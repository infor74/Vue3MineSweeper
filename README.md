# MineSweeper

一个使用 Vue 3、TypeScript 和 Vite 实现的网页扫雷小游戏。

## 环境要求

- Node.js
- Yarn

## 启动项目

```bash
yarn install
yarn dev
```

开发服务器启动后，按终端显示的地址在浏览器中打开游戏。

## 难度

| 难度 | 棋盘大小 | 地雷数 |
| --- | ---: | ---: |
| Easy | 9 × 9 | 10 |
| Normal | 16 × 16 | 16 |
| Hard | 16 × 30 | 30 |

点击难度按钮会开始该难度的新游戏。

## 游戏操作

- **左键**：打开格子。首次有效左键点击的格子不会有地雷；周围格子仍可能有地雷。
- **右键**：在未打开的格子上循环切换标记：无标记 → 旗子 → 问号 → 无标记。
- **重新开始**：重置当前难度的棋盘和计时器。

打开数字格可以看到其周围八格内的地雷数量。打开周围没有地雷的格子时，游戏会继续展开相邻的空白区域和边缘数字格。

## 计时与胜负

计时器从首次生成地雷时开始计时。踩到地雷会显示失败提示；确认提示后会重置当前游戏。

当前实现以旗子数量作为胜利判定：插旗使剩余地雷数减一，标记从旗子切换为问号时加一；剩余地雷数变为零时显示胜利提示。因此，当前判定检查旗子数量是否达到地雷数，不会验证旗子是否标在真正的地雷上，也不会检查所有安全格是否都已打开。

## 构建

```bash
yarn build
```
